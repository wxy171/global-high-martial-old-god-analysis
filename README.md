## 分析原则

1. 区分**正文已确认**、**目录可见但正文未核验**、**分析假设/待验证**。
2. 每个重要结论尽量关联章节和来源。
3. 章节拆解关注叙事功能、信息释放、人物动机、规则机制、伏笔回收与写作技法。
4. 不把标题、简介或早期线索推演成全书定论；随阅读推进持续修订。
