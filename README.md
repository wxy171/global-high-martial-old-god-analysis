- 第91章《空无一物啊》：宁素希望离开，为孩子争取外部世界；姜谜承认自己也希望有人能走出去。
- 第92章《无意义的战术》：萧临发现巨蛛权能无法伤害自己，推断第一代超凡者对权能有特殊位格优势。
- 第93章《奇异生物》：萧临从巨蛛权能中生还后遭遇两名腕足生物袭击，认出它们与卫星镇早期描述的异形人类相似。
- 第94章《逆向》：萧临利用慧魔信息处理能力理解腕足生物语言，并反向通过读心矩阵释放精神污染。
- 第95章《判断》：萧临怀疑村民对通关条件的理解有误，腕足生物可能才是巨蛛权能之后的第二层杀手。
- 第96章《蜘蛛》：萧临提出寻找两名腕足生物作为破局关键，姜谜、宁素、贺恩愿意协助。
- 第97章《破局计划》：研究所难以快速解析腕足生物样本；岳泰州提出用超凡者作为媒介，将深空之瞳带入认知之门。赵凝月回忆与“正义”相关的荒野阻击战及背叛、盗窃。
- 第98章《暗流涌动》：蓝时雨、林念念准备前往大荒野协助；哲人之家思想派/执行派历史被揭示，萧临进入死门被他们误判为必死。
