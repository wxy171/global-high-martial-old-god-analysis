# 第一卷《红境篇》伏笔回收与遗留清单

> 以第146章《他所向往》为第一卷终点。以下编号从既有记录F246之后续编；第99—104章原报告未改动。标记：已回收 / 部分回收 / 未回收 / 新增待追踪。

## 一、死门与腕足文明

- **F247 零一的真实身份**｜已回收：零一是腕足生物，承担守护立方体与清除进入者的任务。
- **F248 零一的记忆加密**｜已回收：系统解除加密后恢复其原始使命记忆。
- **F249 村庄安全区的真实性质**｜已回收：村庄是腕足生物为节省资源建立的误导性区域，并非真正通关路径。
- **F250 腕足生物的读心矩阵**｜部分回收：既能读取思想与协调战术，也能被萧临反向污染；系统底层仍未知。
- **F251 巨蛛是否为死门最终威胁**｜已回收：巨蛛只是战场循环的一部分，腕足生物与立方体才构成另一层关键机制。
- **F252 岳泰州头颅与立方体**｜部分回收：头颅位于立方体内并接入未知系统，保存目的未明。
- **F253 节点系统的权限结构**｜部分回收：节点可调用武器与护盾，萧临拥有最高优先级；系统创造者未明。
- **F254 岳泰州是否仍有意识**｜未回收：腕足生物认为需其本人允许才能出现无编号接入者，暗示其意识可能仍在。
- **F255 腕足文明的真正目的**｜未回收：他们讨论如何控制岳泰州，也担忧战争复活；其文明结构和最终目标未知。

## 二、战争与法典

- **F256 方尖碑铭文的警告**｜已回收：铭文明确记载战争幼虫被放逐于此，禁止法典重现。
- **F257 法典被污染的来源**｜已回收：战争幼虫通过低语和生命力影响法典，并借陈平国推动现实化。
- **F258 陈平国为何成为代理载体**｜部分回收：其在二重遗迹接触早期超凡者低语并获得法典；该超凡者身份未明。
- **F259 战争幼虫吞噬生命的机制**｜已回收：红黑光须抽取生命力并将受害者纳入身体，成为其成长资源。
- **F260 战争幼虫如何承载战争意识**｜已回收：吸收生命力后优先进化神经元，足以承载战争意识。
- **F261 战争的复活条件**｜部分回收：战争称“接受某个答案”便会归来；具体答案与条件仍未知。
- **F262 战争是否真正被消灭**｜部分回收：幼虫再次被放逐，但战争意识与复活机制仍未被彻底根除。
- **F263 法典作为囚笼与共同仪式的双重性质**｜已回收：受污染时成为幼虫突破封印的工具；重建后成为人类文明共同仪式。
- **F264 法典能否永久封印战争**｜未回收：第一卷仅确认再次放逐，长期有效性未验证。

## 三、命运与超凡能力

- **F265 萧临第一代身份**｜已回收：多处角色确认其为零号/最初超凡者。
- **F266 作家能力与自由意志边界**｜部分回收：命运干预不能直接覆盖自由意志；萧临通过自我主角化建立命运倾向。
- **F267 命运引导能否改变战争未来**｜未回收：萧临写下新的英雄史诗，效果仅表现为方向指引。
- **F268 秘文的来源**｜部分回收：陈平国称其来自更强大的超凡者所留下领域，源头未明。
- **F269 七种秘文是否完整**｜未回收：现有资料仅列光、热量、毁灭、衰败、穿透、优化、劣化。
- **F270 船长象征物的异常再超凡化**｜部分回收：萧临注入本质后重塑大船，但其复苏前的异常反应原因未明。

## 四、人物与组织

- **F271 莉莉与岳泰州的命运交织**｜未回收：兜帽组织因这一联系带走莉莉，显示其可能是追踪岳泰州的关键。
- **F272 兜帽组织的身份与首领**｜未回收：其首领通过命运启示窥见莉莉，组织目的和层级未知。
- **F273 赵凝月与蜘蛛的关系**｜未回收：她对腕足生物特征表现异常，对蜘蛛也有明确厌恶，真实经历未揭示。
- **F274 赵凝月与战争的仇恨**｜部分回收：战争复活时赵凝月出现强烈创伤反应，说明她与战争有深层历史关系。
- **F275 杨奇与正义、灾厄的旧事**｜部分回收：杨奇曾参与围杀战争，赵凝月提到正义与灾厄的背叛、决裂、盗窃；事件全貌未明。
- **F276 哲人之家思想派的后续**｜未回收：程玉与莉莉被兜帽组织截获后，思想派未来与悬海势力格局未明。

## 五、蓝灾与红境治理

- **F277 蓝灾复耕与农业恢复**｜未回收：研究所认为可能找到破解办法，萧临要求优先保障粮食生产。
- **F278 蓝灾图腾柱与古战场关系**｜部分回收：图腾柱为蓝灾源头，古战场向现实渗透机制仍需深化。
- **F279 红境城市对蓝龙矿业的依附**｜部分回收：第一卷末各城市与势力投诚，但长期治理结构尚未验证。
- **F280 红河城升格后的社会后果**｜部分回收：原有城市下沉至一重现实，法典造物留在二重现实；居民与行政重建仍在进行。

## 六、第一卷已完成的主要回收链

1. 西蒙故事计划 → 白啸云死亡 → 萧临继承黑伞并复仇 → 西蒙器官改造厄化 → 西蒙死亡。
2. 蓝灾 → 古战场图腾柱 → 认知之门 → 巨蛛杀戮与深红云层起源。
3. 死门村庄 → 零一记忆加密 → 腕足生物身份 → 节点系统 → 岳泰州头颅与未知空间。
4. 哲人之家法典计划 → 红河城升格 → 战争幼虫污染 → 战争复活 → 文明共同仪式再次放逐。
5. 萧临命运史诗 → 命运引导 → 第一卷结尾追踪战争。
